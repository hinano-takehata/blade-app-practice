# blade-app-practice

## 概要
COACHTECH 教材 Tutorial 9-2「Bladeテンプレート ハンズオン演習」で作成した成果物です。
提供されたBladeファイルを読み解き、コントローラーから適切なデータを渡して、「商品ページ一覧」を表示できるようにした。

## 使用技術
- PHP 8.5
- Laravel 10.5
- Blade テンプレート

## 学んだこと
- 提供されたBladeファイルから、必要な変数を特定し、コントローラーで準備する流れを学んだ。
- また、コントローラーで変数に対応する値がないと一度Laravelでエラーが出たので、変数の特定をし直し、コントローラーに追加した。
- @ifと@forelseを使用することによるデータの表示の仕方を学んだ。

## 動作確認
http://localhost/products
にアクセスし、完成イメージと同じ画面が表示されたかを確認した。
また、在庫状態を変えてみたり、完成イメージにない商品を一つ増やして反映されるか確認した。
